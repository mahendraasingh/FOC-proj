# 🧠 RotBrain — See Your Brain Rot in Real-Time

> **Break free from the infinite scroll with a live floating Android companion.**

RotBrain gamifies doomscrolling awareness by projecting an interactive, floating system mascot over your short-form media apps (Instagram Reels, YouTube Shorts, and TikTok). As continuous watch time climbs, the mascot visibly decays through four distinct neural stages.
